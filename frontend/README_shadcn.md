Shadcn/ui integration notes

This project includes simple UI components under src/components/ui that mimic the shadcn/ui style using Tailwind CSS (Button, Input).

To use full shadcn/ui components, follow these steps:

1. Install shadcn CLI and required packages (example):
   npm install @shadcn/ui @radix-ui/react-tooltip @radix-ui/react-dialog

2. Run the shadcn CLI (if available) to generate components into your project.

3. Ensure Tailwind CSS is configured (tailwind.config.cjs present) and run the app.

Note: The shadcn/ui system often requires a design token setup and additional dependencies. If you want, I can add exact package installation and example generated components once you confirm which shadcn package set you want to use.
